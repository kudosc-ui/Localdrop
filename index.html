            Demo Mode

            Simulate multiple devices in separate browser tabs to test sync without physical hardware. Demo devices only connect to other tabs of this same browser — see Help.

            How syncing actually works

            LocalDrop has no server. Two devices connect to each other directly (WebRTC), and the very first connection has to be made by you — by scanning a QR code or exchanging a short manual code between the two devices. After that, clipboard text and files flow directly between them with nothing in the middle.

            About "automatic" clipboard sync

            Browsers don't provide a way to watch the clipboard continuously in the background — that's a deliberate privacy restriction, not a LocalDrop limitation. When your browser grants clipboard-read permission, LocalDrop reads it when you tap Sync Clipboard, and opportunistically when this tab regains focus. If your browser blocks programmatic reads entirely, use Paste & Sync instead.

            About Demo Mode

            Demo Mode uses a browser feature called BroadcastChannel, which only reaches other tabs/windows open in this same browser on this same device. It's genuinely useful for testing the multi-device sync flow — favoriting, history, loop prevention — without needing a second physical device. It is not a way to reach your actual phone or laptop; use Connect Device (QR or Manual Code) for that. One quirk worth knowing: because demo tabs share the same browser storage, clipboard history can look shared between them even though the sync messages themselves travel one at a time, correctly, over BroadcastChannel — on two separate real devices, history is never shared this way.

            About Manual Code pairing

            The "code" is a compressed copy of the real connection handshake, grouped into chunks for readability. It's longer than a 6-digit PIN because, without a server to look codes up against, the code has to carry the whole handshake itself. QR Code pairing carries the same data — just scanned instead of typed.

            Local network only

            LocalDrop never uses third-party STUN/TURN or relay servers, so connections are limited to devices that can reach each other directly — typically the same Wi-Fi network. It also means it won't work across two different networks (e.g. over mobile data).
